# crate-3d
a 3d crate dodging game. I made this mainly to train my three.js skills.
It was hard making this with so little data to spare (I chose the lightweight card) to make a 3d game where the player moves and jumps in 3d, with dropping platform, but <b>i'm proud of making a 3d game in less than 10KB!!</b>

Basically, you use arrow keys to move, and space to jump. <b>This means that you cannot play this game on mobile.</b> The yellow boxes are indicators, which is a sign of the boxes going to drop. Don't touch the bottom of the boxes, that is how you die.
